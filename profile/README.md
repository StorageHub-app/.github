<h1 align="center">StorageHub</h1>

<p align="center">
  For people who move files they cannot afford to lose.
</p>

StorageHub is a file manager, transfer client, and synchronization engine for
Windows. Put local disks and remote storage side by side in one window. Queue a
transfer and close the window — it keeps running. Synchronize two locations and
see exactly what is about to change before anything is touched.

Credentials live in an encrypted current-user vault and never reach a profile
file, a log, or a diagnostic bundle. No server is trusted until its certificate
or host key has been confirmed. Every delete, overwrite, and resume is its own
decision, and a provider that cannot enforce one refuses the operation instead
of approximating it.

- **[StorageHub](https://github.com/StorageHub-app/StorageHub)** — the
  application: browser, transfer queue, sync engine, scheduler, background
  agent, and SSH terminal. Local/UNC, S3, FTP, FTPS, and SFTP.
- **[Releases](https://github.com/StorageHub-app/StorageHub/releases)** —
  per-user installer, MSI, and portable build for Windows x64.
